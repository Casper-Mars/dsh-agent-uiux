# 品味层：把「能用」做成「好看且不俗」

模型默认会收敛到最安全的通用风格：Inter 字体、白底紫渐变、几乎无动效。
这正是要避开的。本技能把审美拆成四个可执行的轴——**字体、动效、背景、主题**——
每个轴给「避开什么 / 优先什么」，让改动能落到代码。

字体细则见 `references/typography.md`；动效与背景见 `references/motion-and-background.md`。

## 四个轴

### 1. 字体（最强的气质信号）

- 不要：Inter / Roboto / Open Sans / Lato / 系统默认，除非品牌明确要求。
- 代码气质：JetBrains Mono、Fira Code、Space Grotesk。
- 编辑感：Playfair Display、Crimson Pro、Newsreader。
- 技术理性：IBM Plex Sans / IBM Plex Mono、Source Sans 3。
- 有个性：Bricolage Grotesque、Newsreader。
- 标题与正文可以同一家族不同字重，不要硬凑两种不搭的字体。

### 2. 动效（服务引导，不炫技）

- 入场用一次、克制；交互反馈要即时。
- 时长：微交互 120–200ms，元素入场 200–400ms，页面切换 ≤ 400ms。
- 缓动：ease-out 入场，spring 用于可拖拽/物理感。
- 永远尊重 `prefers-reduced-motion: reduce`，关掉位移与视差。

### 3. 背景（别再用纯白 + 紫渐变）

- 用带色相的中性底、细网格、柔光斑、噪点、分形渐变——选一个，别叠满。
- 深色主题不是纯黑：低亮中性 + 提亮的主色。
- 渐变要有方向与理由，不做「从上到下紫到白」这种默认货。

### 4. 主题（一致性 > 单点惊艳）

- 一套界面只用一套阴影、圆角、间距语言。
- 强调色只出现在真正需要引导的地方。
- 深浅两套主题都要单独调，不互相反色。

## 自检

- 关掉颜色，只看灰阶，层级还清楚吗？
- 换掉字体，气质还成立吗？（如果靠字体撑，说明结构太弱）
- 动效全关，功能还完整吗？
- 第一眼有没有记忆点，而不是「又一个模板」？

## 反合理化

| 借口 | 现实 |
|---|---|
| 用户就喜欢简单的白底 | 简单≠通用 AI 风；克制也可以有记忆点 |
| 动效太花时间 | 少量对的动效比一堆错的好；先加反馈类 |
| 字体无所谓 | 字体是第一眼气质的最大变量 |
| 先这样，回头再调 | 默认货一旦上线就定型了，回头成本更高 |
