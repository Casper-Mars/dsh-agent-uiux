# 动效与背景

## 动效时长与缓动

| 场景 | 时长 | 缓动 |
|---|---|---|
| 微交互（按钮、hover） | 120–200ms | ease-out |
| 元素入场 | 200–400ms | ease-out / cubic-bezier(.2,.8,.2,1) |
| 弹层 / 抽屉 | 200–300ms | ease-out |
| 页面切换 | ≤ 400ms | ease-in-out |
| 可拖拽 / 物理感 | 依交互 | spring |

## 动效原则

- 入场只做一次，不无限循环（除 loading）。
- 反馈要即时：按下/悬停 100ms 内要有变化。
- 位移优先用 transform / opacity（GPU 友好），不动 layout 属性。
- 关闭动效：`@media (prefers-reduced-motion: reduce)` 关掉位移、视差、自动播放。

## 背景做法（选一个，别叠满）

- **带色相中性底**：暖灰 / 冷灰，比纯白有质感。
- **细网格 / 点阵**：科技、工具类，低对比。
- **柔光斑**：品牌色低透明度大圆模糊，营造氛围。
- **噪点纹理**：极低透明度，压住数字感的塑料味。
- **分形 / 渐变**：有方向、有理由，不做「上紫下白」默认货。
- **深色主题**：低亮中性（#0B–#16），主色提亮一档，阴影改边框。

## 反例（一眼 AI）

- 白底 + 紫色对角渐变 + 大圆角卡片 + Inter + 一堆浮动光球。
- 每个素材都带彩色投影。
- 深色模式是亮色取反。
