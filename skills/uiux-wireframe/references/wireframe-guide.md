# 线框绘制约定

## 画布与栅格

- 桌面：1440 宽，12 列栅格，边距 64。
- 平板：1024 宽，8 列。
- 移动：390 宽，4 列，边距 16。
- 所有元素对齐栅格，不凭手感摆。

## 元素约定

- 文本：实线小方块代表一行字，长度反映真实文案。
- 图片/媒体：方框 + 一条对角线。
- 按钮：圆角矩形，主按钮黑底，次按钮描边。
- 输入框：描边矩形 + 左侧标签线。
- 图标：16/20 方框占位。
- 导航：顶栏或侧栏灰底块，标当前项。

## 每屏结构模板

```
[导航 / 面包屑]
[页面标题 + 主操作]
[主内容区（列表 / 表单 / 卡片）]
[辅助区（筛选 / 详情 / 帮助）]
[底部操作 / 分页]
```

## 标注

- 区块编号 ①②③，旁边写「这是什么 + 交互点」。
- 需要人拍板的结构决策单独标「?决策」。
- 需要后面定视觉的点标「视觉」。

## 状态

- default / empty / loading / error 各一张。
- 列表页加 long-list（滚动 / 虚拟列表）。
- 表单页加校验错误态。
