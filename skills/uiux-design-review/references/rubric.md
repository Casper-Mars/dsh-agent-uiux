# 设计评审 rubric

每维度 0–2 分；任一维度 0 分整体不通过。

## 1. 结构（0–2）

- 2：层级清楚，主操作唯一且醒目，栅格对齐，扫读顺畅。
- 1：能看懂，但主次不清或对齐松散。
- 0：找不到下一步 / 结构混乱。

## 2. token 合规（0–2）

- 2：全部用语义 token，无裸 hex/px（token 定义处除外）。
- 1：少量脱轨值但有理由。
- 0：大量魔法值、颜色名当变量名。

## 3. 状态覆盖（0–2）

- 2：default/empty/loading/error/disabled/focus 齐全且有图。
- 1：缺 1–2 个次要状态。
- 0：只有 default 或空/错态是白屏。

## 4. 可访问性（0–2）

- 2：正文对比度 ≥4.5:1，焦点可见，触控 ≥44，语义标签齐全。
- 1：个别不达标。
- 0：对比度不足 / 焦点丢失 / 只能鼠标操作。

## 5. 反 AI-slop（0–2）

- 2：字体有选择、背景有处理、层次不只靠颜色、有记忆点。
- 1：部分通用但整体成立。
- 0：Inter + 白底紫渐变 + 无动效的默认货。

## 汇总

- 8–10：通过。
- 5–7：需修改后复审。
- 0–4 或任一 0：不通过。
