# Token 角色速查

## 颜色

- `bg`：页面最底层背景。
- `surface`：卡片 / 弹层 / 输入框底色，比 bg 略提亮或略压暗。
- `border`：分隔线、描边；分 `subtle` 与 `strong`。
- `text`：主文字；`textMuted`：次要 / 辅助；`textDisabled`。
- `primary`：主操作色；`onPrimary`：主色上的文字（多为白或近黑）。
- 语义：`success` / `warning` / `danger` / `info`，每个配一个浅 `*-subtle` 底。

## 间距

- 基于 4 或 8 的栅格：4/8/12/16/24/32/48/64。
- 组件内间距用 `space.1..4`，区块间距用 `space.6..12`。
- 不要在组件里直接写 `13px` 这种脱轨值。

## 圆角

- `sm`（4–6）：输入框、小标签。
- `md`（8–12）：按钮、卡片。
- `lg`（16–24）：大卡、弹层。
- `full`：胶囊、头像。

## 阴影

- `sm`：贴地、细微；`md`：卡片悬浮；`lg`：弹层 / 模态。
- 深色模式下阴影几乎不可见，改用边框 + 提升背景亮度区分层级。

## 字体

- 字号阶：12 / 14 / 16 / 20 / 24 / 32 / 40。
- 行高：正文 1.5–1.7，标题 1.1–1.3。
- 字重：正文 400，强调 500–600，标题 600–700。
- 数字：表格/统计用等宽或 `font-variant-numeric: tabular-nums`。
