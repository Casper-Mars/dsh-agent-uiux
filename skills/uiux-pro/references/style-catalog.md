# 风格库（按气质归类）

不是越多越好。按 brief 的气质先缩小到 2–3 个，再展开。每个风格都写清「适合 / 不适合」。

## 克制 / 专业

- **功能主义（Functional）**：灰阶为主、极少装饰、信息层级靠排版与间距。
  适合 B 端工具、后台、开发者产品。不适合需要情绪价值的 C 端。
- **Swiss / 网格（International）**：严格栅格、无衬线、左对齐、大留白。
  适合专业服务、企业官网。不适合高密度数据表。
- **企业克制（Corporate clean）**：蓝 / 中性基调、卡片刻度、轻投影。
  适合金融、SaaS、企业级。风险是容易平庸，需要一点品牌细节救场。

## 亲和 / 温度

- **友好圆润（Soft / Friendly）**：大圆角、暖色、柔和阴影、圆体字。
  适合消费、教育、社区、健康。不适合严肃合规场景。
- **杂志感（Editorial）**：衬线标题 + 大图 + 强对比、非对称。
  适合内容、媒体、品牌站。不适合密集操作界面。

## 技术 / 极客

- **终端美学（Terminal）**：等宽字、深底、荧光点缀、块状光标。
  适合开发者工具、黑客松、极客品牌。不适合大众消费品。
- **数据优先（Data-dense）**：紧凑行高、表格数字、克制的强调色。
  适合看板、监控、运维。

## 大胆 / 表现力

- **大胆对比（Bold contrast）**：超大字号、强互补色、不对称、破格。
  适合落地页、活动页、创意品牌。不适合长期高频使用。
- **粗野主义（Neo-brutalism）**：硬边框、纯色块、无阴影、系统字体混排。
  适合个性品牌、潮牌、独立产品。不适合需要信任感的金融。

## 静谧 / 高端

- **静谧极简（Quiet luxury）**：大量留白、低饱和、精致细字、克制动效。
  适合高端消费、美妆、咨询。需要极强的排版功底，否则显得空。
- **玻璃拟态（Glassmorphism）**：半透明模糊、光斑、层次。
  适合展示型、音乐/创意。不适合作为复杂表单的主视觉（可读性差）。
