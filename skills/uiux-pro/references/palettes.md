# 配色方案库

规则先于色号：**一个主色 + 一套中性阶 + 四个语义色**。主色只服务一个目的，
中性色承担 90% 的面积，语义色永远表达固定含义。

## 通用规则

- 文本对比度：正文 ≥ 4.5:1（WCAG AA），大字 ≥ 3:1。
- 主色不要用来铺大背景（除营销 Hero）。
- 语义色固定：成功=绿、警告=琥珀、错误=红、信息=蓝，跨产品一致。
- 深色模式不是反色：单独定义一阶，不是把亮色值取反。

## 中性阶模板（亮色）

- `--bg` 最浅底、`--surface` 卡片、`--border` 分隔、`--muted` 次要文字、
  `--text` 主文字、`--text-strong` 标题。
- 推荐用带一点色相的中性（暖灰 / 冷灰），比纯灰更有质感。

## 主色方向（按气质选）

| 气质 | 主色方向 | 注意 |
|---|---|---|
| 专业信任 | 蓝 / 靛 | 最常规，需靠字体与布局拉开差异 |
| 亲和温暖 | 珊瑚 / 橙 / 暖绿 | 避免大面积高饱和，伤眼 |
| 科技前沿 | 青 / 紫 / 电光蓝 | 紫渐变易撞 AI 味，慎用大面积 |
| 高端静谧 | 墨绿 / 酒红 / 香槟金 | 用低饱和 + 大量留白 |
| 个性大胆 | 荧光黄 / 亮粉 / 撞色 | 只用在强调点，不做主体 |

## 语义四色（可直接起步，自行调校到对比达标）

- 成功：#15803D / 浅底 #DCFCE7
- 警告：#B45309 / 浅底 #FEF3C7
- 错误：#B91C1C / 浅底 #FEE2E2
- 信息：#1D4ED8 / 浅底 #DBEAFE

## 深色模式

- 背景不是纯黑（#000），用 #0B0B0C–#15161A 的低亮中性。
- 文字不是纯白，用 #E8E8EA，降低眩光。
- 主色在深色下要提亮一档，否则发闷。
