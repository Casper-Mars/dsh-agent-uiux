# 设计智能推荐：风格 / 配色 / 字体 / 动效

把 `design brief` 里的「气质」翻译成一组可执行的设计参数。输出不是「我觉得好看」，
而是**带理由的候选组合**，让人能对比后拍板。

风格库见 `references/style-catalog.md`；配色方案见 `references/palettes.md`；
推荐卡片按 `assets/recommendation-card.md` 填。

## 输入

- brief 里的产品类型与气质三词（没有就先读 `uiux-discovery`）。
- 品牌资产（有就作硬约束，没有才自由推荐）。

## 推荐流程

1. **锁定产品类型**：类型决定密度与基调，先过滤掉明显不合适的风格。
2. **选 2–3 套风格候选**：从 `references/style-catalog.md` 里挑，按气质匹配度排序。
   每套给「适合什么 / 不适合什么」，不做无差别堆砌。
3. **配一套色板**：从 `references/palettes.md` 选中性色 + 一个主色 + 语义色。
   主色不超过 1 个；语义色（成功/警告/错误/信息）固定语义。
4. **配对字体**：一个正文 + 一个标题（或同一家族不同字重）。给 2 组备选。
5. **定动效基调**：克制（B 端）/ 有节奏（C 端）/ 可张扬（营销页），给出时长与缓动区间。
6. **写清取舍**：为什么选这套、牺牲了什么、什么情况下要换。

## 风格 ↔ 产品类型匹配（速判）

| 产品类型 | 倾向风格 | 避免 |
|---|---|---|
| B 端工具 | 干净功能风、Swiss / 网格、企业克制 | 重装饰、大插画、玻璃拟态 |
| C 端应用 | 友好圆润、柔和拟物、杂志感 | 过于冷硬的纯灰 |
| 落地页 | 编辑排版感、大胆对比、动态 | 中庸无记忆点的通用模板 |
| 看板 | 数据优先、低饱和、留白 | 花哨渐变盖过数据 |
| 移动 App | 平台原生 + 品牌点缀 | 桌面式密集布局 |

## 输出

按 `assets/recommendation-card.md` 产出 2–3 张卡片，每张含：风格名、为何适合、
色板（含对比度提示）、字体配对、动效基调、风险。

## 反合理化

| 借口 | 现实 |
|---|---|
| 直接用 Inter + 紫渐变最保险 | 那是最「安全」也最没记忆点的选择，正是要避开的通用 AI 味 |
| 多给几套总没错 | 超过 3 套等于没推荐；候选要有排序和理由 |
| 配色我随便配个好看的 | 颜色要服务语义与对比度，不服务「好看」 |
| 动效越多越高级 | 动效服务引导与反馈，炫技会拖慢并分散注意 |
